# Veo / Gemini — пак №6: POV з каблучкою + телефон із вимкненим екраном

Digital-only: ніякого паперу, конвертів, воскових печаток і стрічок — продукт
живе на екрані, тож і сцени мають бути «екранні».

Два блоки:
- **POV з каблучкою (1–5)** — перша особа, її руки, її каблучка, її телефон.
  Дає ідентифікацію → підписки.
- **Телефон із вимкненим екраном (6–10)** — під вставку продукту в екран у
  композитингу.

## Технічна умова для «телефонних» кадрів (6–10)

Щоб я могла вставити продукт прямо в екран:
- камера **на штативі**, без зуму й перекадрування;
- телефон **не рухається**, усі **чотири кути екрана видно** весь час;
- **без відблисків і бліків** на склі (світло збоку/розсіяне);
- екран вимкнений — плоске темне скло, нічого не світиться.

Якщо кадр тремтить або телефон виходить із кадру — кліп усе одно годиться,
але вже тільки як перебивка, без вставки продукту.
