# VistelaCo — репозиторій контенту

Тут дві окремі частини:

1. **Content factory** (корінь: `build.py`, `render*.py`, `queue/`, `.github/workflows/`) — автоматичні піни й каруселі для Make. Опис у README.md. Не змінювати без прямого прохання.
2. **Instagram studio** (`studio/`) — ручний контент для Instagram VistelaCo: рілси з гачками, каруселі, сторіс, хайлайти. Коли Діана кидає відео чи фото або просить рілс / карусель / сторіс / хайлайти — працюй тут за правилами нижче.

Діана спілкується українською, коротко й чесно; факти не вигадувати.
