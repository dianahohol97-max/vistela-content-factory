# VistelaCo Content Playbook 2026 (з аналізу західного ринку)

Довідник для генерації контенту: формати відео, хуки, теми каруселей,
Pinterest-титули, хештеги, сезонність. Джерело — дослідження соцмедіа-стратегій
The Knot / Minted / Zola / Paperless Post / Greenvelope + бенчмарки 2026.

Використання: недільна сесія затвердження бере теми каруселей звідси;
хуки рілсів ротуються з `config.py` (SHOWCASE_HOOKS / PRODUCT_TOUR_HOOKS);
нові піни — титули/описи за зразками нижче.

## 1 · Формати короткого відео (Reels / TikTok)

1. **Invitation Suite Reveal** — коробка/конверт → розкриття → flatlay. 7–15 с.
2. **ASMR Assembly** — руки, віск, wax seal, стрічка; чистий звук. 15–30 с.
3. **Digital STD "plays your song"** — екранний запис під трек. 7–12 с.
4. **Before / After** — дефолтний шаблон → наш дизайн. 8–12 с.
5. **"Don't do this" / Mistake PSA** — типова помилка + рішення. 15–25 с.
6. **Etiquette explainer** — правило текстом на екрані. 20–40 с.
7. **POV storytime** — "POV: you just got engaged…" + b-roll. 10–20 с.
8. **Budget breakdown** — paper vs digital, ціни. 20–35 с.
9. **Trend-jacking** — "5 invitation trends 2026" нарізка. 12–20 с.
10. **Tutorial / screen recording** — сайт за 60 секунд. 20–45 с.
11. **Comparison** — paper vs digital split-screen. 15–25 с.
12. **"Things nobody tells you"** — список. 20–40 с.
13. **Design timelapse** — процес у Canva/AI. 8–15 с.
14. **Unboxing** цифрового пакета. 10–20 с.
15. **Seasonal / countdown** — "Engagement season is here". 10–20 с.

Механіка: хук у перші 1–2 с (≤12 слів), текст у верхній третині (низ ~150px і
верх ~120px перекриває UI), burned-in субтитри завжди, мікро-payoff кожні
2–3 с, loop-ending (фінальний кадр веде в перший).

## 5.1 · SEO в підписі (не тільки хештеги)

IG і TikTok індексують **текст** підпису, не лише теги. Тому кожен підпис
збирається за структурою (`build._captions`):

1. хук 🤍
2. вигода одним реченням
3. **SEO-речення** — ключі природною мовою: `animated save the date video`,
   `digital save the date template`, `edit in Canva`, `wedding website
   template with RSVP`
4. `This <keyword> is on Etsy — link in bio.`
5. коментар-гейт (`Comment "DATE"…`)
6. стек хештегів: 12 тегів = широкі + нішеві + рік нареченої

Ключі задаються в `config.PRODUCT_COPY[cat]["ig_seo"]` та `["ig_hashtags"]`
окремо для save the date / website / invitation, TikTok має свій стек.

## 6 · Аудіо-стратегія

Трендовий звук: <5 000 uses зі стрілкою вгору = золото; >100K uses = пізно.
TikTok-звуки мігрують у Reels через 1–2 тижні — бери на IG те, що пікнуло на
TikTok. Для reveal/ASMR — оригінальний звук. Business-акаунт обмежений у
комерційній музиці — перевіряй доступність звуку зі свого акаунта.

## 7 · AI-контент: правила

- Безпечно: анімовані reveal, motion, b-roll, фони, мокапи, timelapse,
  POV-сцени без «видавання за клієнтів».
- НЕ можна: фейкові пари-«відгуки», AI-люди як «реальні клієнти».
- Лейбли: TikTok — обов'язковий AIGC-лейбл для реалістичних людей/сцен
  (автодетекція C2PA, санкції за приховування); Instagram — «AI Info» у
  розширених налаштуваннях. Правило: when in doubt, disclose.

## 8 · Сезонність (Western wedding cycle)

- **Лис–лют:** engagement season (~47% заручин Thanksgiving→Valentine's;
  пік — Різдво). Контент: just engaged, save the dates, палітри, where to
  start. Готувати з вересня–жовтня (за 45–90 днів).
- **Січ–бер:** пік planning-пошуків → save the date + website + wording.
- **Бер–тра:** invitation season під літні весілля (etiquette, RSVP).
- **Тра–жов:** peak wedding months → website/RSVP, real couples.
- **Вер–жов:** розгін engagement-season контенту наперед.

## 9 · Бенчмарки / пороги

- Новий акаунт перші 90 днів: −30–50% від середніх метрик — це норма.
- Reels: 65% переглядів у перші 3 дні; смол-акаунт = сотні переглядів/Reel
  — норм. 15 відео поспіль <500 переглядів → міняти хук/перші 2 с, не тему.
- TikTok: дивитись views + completion (>40%), не підписників.
- Pinterest: save-rate ціль 2–4%; outbound CTR static 0.2–0.8% (ціль 1–1.5%);
  реальна тяга після 90 днів. <100k показів або save-rate <2% за 90 днів →
  переглянути ключі й дизайн (світле тло, титул 40–60 симв.).
- Carousel swipe-through slide1→2: 60–75% ок, <50% — переробити hook-слайд.
